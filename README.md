## Overview
The Weather Dashboard is an interactive data visualization project developed using Microsoft Power BI and Weather API. The project focuses on transforming real-time weather data into meaningful insights through an intuitive and visually appealing dashboard.

It provides an overview of current weather conditions, upcoming forecasts, air quality levels, and other important environmental indicators across different cities.

## Key Features
- **Current Weather:** Displays temperature, weather conditions, and location details.
- **Weather Forecast:** Visualizes upcoming weather trends and temperature changes.
- **Air Quality Index (AQI):** Monitors air quality and pollutant levels, including PM2.5, PM10, CO, SO2, O3, and NO2.
- **Sunrise & Sunset:** Displays daily sunrise and sunset timings.
- **Weather Metrics:** Includes humidity, wind speed, visibility, pressure, UV index, and precipitation.
- **Chance of Rain:** Visualizes the probability of rainfall across forecast days.
- **Multiple Cities:** Allows weather conditions to be viewed across different locations.

## Tools & Technologies

## Project Objective
The main objective of this project is to integrate weather data from an external API and transform it into an interactive Power BI dashboard, making weather information easier to understand through visual analytics.
